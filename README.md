## Overview

This project performs Exploratory Data Analysis (EDA) on a global university rankings dataset. The goal is to understand how universities are distributed across countries, how ranking scores and indicators vary, and what patterns can be observed among top-ranked institutions.

The project covers the full analysis workflow: data loading, data cleaning, missing-value handling, exploratory analysis, visualization, and documentation of key findings.

## Business Questions

- Which countries have the highest number of ranked universities?
- How are universities distributed across ranking positions?
- Which indicators have the strongest relationship with overall rank or score?
- How do top-ranked universities differ from lower-ranked universities?
- What patterns can be observed across countries, regions, or ranking categories?
